# Neon Bloom

An animated neon flower bouquet drawn by luminous shooting-star trails.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy with Vercel

1. Push this repository to GitHub.
2. Import the repository in Vercel.
3. Vercel automatically detects Vite and uses `npm run build` with `dist` as the output directory.
